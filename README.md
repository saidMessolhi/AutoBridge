# منصة AutoBridge SaaS | AutoBridge SaaS Platform

منصة سحابية متكاملة رائدة لإدارة وتتبع عمليات استيراد السيارات من الصين، توفر تتبعاً فورياً للمراحل، وإدارة وثائق ذكية، وسير عمل منظماً ومقيداً بالصلاحيات والأدوار.

An advanced, comprehensive SaaS platform for managing and tracking vehicle imports from China, featuring real-time stage updates, intelligent document management, and strict role-based access control (RBAC).

---

## 🚀 الميزات الرئيسية | Key Features

### 1. إدارة وتوزيع الأدوار الوظيفية (Multi-role Workspace)
تتحكم المنصة في الصلاحيات والإجراءات بدقة بالغة وفق الأدوار الوظيفية التالية:
* **المدير العام (General Manager):** يتمتع بصلاحية الإشراف الكاملة، واعتماد أو تعديل كافة المراحل والوثائق والعمليات المالية واللوجستية.
* **عون استقبال / مسؤول ملفات (File Manager):** مراجعة الملفات الأولية، ورفع وثائق الهوية، ومطابقة وثائق الزبون الثبوتية لتنشيط استلام ملف المركبة.
* **مسؤول الصين (China Operations):** تنظيم عقود الشراء الأولية، وإصدار تقارير المعاينة الفنية للسيارة الصينية في أرض الميدان.
* **مسؤول اللوجستيك (Logistics Professional):** تحديث بوليصة الشحن (BL)، رفع صور الحاوية في الميناء، وإرفاق وصولات الشحن الدولي بحراً وبراً.
* **المخلص الجمركي (Customs Broker):** معالجة الرسوم، رفع شهادات المطابقة الفنية والمستند الجمركي الموحد (سند الخروج جمركياً).
* **المحاسب (Accountant):** متابعة الإيصالات البنكية ومطابقة الدفعات المالية والتحويلات الخارجية.
* **زبون استيراد (End Client):** تتبع تقدم شحن سيارته خطوة بخطوة، وتقديم المستندات الثبوتية المطلوبة بشكل مباشر وبخصوصية تامة.

### 2. إدارة الوثائق الذكية والمقيدة بالأدوار (Smart Document Center)
* **واجهات تحميل مخصصة (Contextual & Isolated Upload Pages):** لم يعد هناك نموذج تحميل عام موحد؛ بل تظهر صفحة تحميل مخصصة تفصيلية عند الضغط على مستند بعينه (مثل: نسخة ملونة جواز السفر، أو تفويض عقد الوكالة، أو وصل تحويل بنكي).
* **تفعيل مقيد بالصلاحيات (Role-Based Restriction):** يتم تفعيل وتنشيط رفع الوثائق فقط للموظف المعني والمخوّل برفع ذلك النوع من المستندات تحديداً، بينما تظهر الوثائق الخارجة عن الاختصاص مغلقة ومحمية.
* **تصدير لملفات PDF بنقاوة فائقة (High-Fidelity PDF Export):** نظام موحد لإنشاء وطباعة التقارير الفنية ووصولات الاستلام بصيغة PDF مباشرة من المتصفح مع دعم كامل للبيئات المحمية وخطوط الويب.

### 3. تتبع المسار اللوجستي والجمركي (Import Pipeline Tracking)
* تنظيم المعاملات على خط زمني ديناميكي يغطي أدق التفاصيل من الفحص الأولي بالصين وحتى التسليم النهائي في الميناء المحلي.

## 🛠️ التقنيات المستخدمة | Tech Stack

* **Front-End:** React 19, TypeScript
* **Routing:** React Router v7
* **Styling:** Tailwind CSS (Engine v4)
* **Animations:** Motion (`motion/react`)
* **Icons:** Lucide React
* **Database & Auth:** Firebase Firestore & Firebase Authentication
* **PDF Utility:** jsPDF & html2canvas

## 💻 التشغيل والتطوير | Local Development & Run

### 1. تثبيت الحزم التبعية
```bash
npm install
```

### 2. تشغيل بيئة التطوير المحلية
تنطلق المنصة محلياً على المنفذ الافتراضي المعتمد `3000`:
```bash
npm run dev
```

### 3. بناء نسخة الإنتاج الجاهزة للنشر
```bash
npm run build
```

### 4. فحص جودة وصحة الأكواد (Linting)
```bash
npm run lint
```

## 🔒 الأمن وقواعد الحماية | Firestore Rules & Security

تم ترميز قواعد الأمان بملف `firestore.rules` لتدقيق العمليات استناداً إلى أدوار الموظفين المدونة ببيانات التسجيل الأساسية. يمنع النظام تماماً تزييف الأدوار أو تعديل حالات المستندات دون التوقيع الرقمي وصلاحيات الهيكل المعتمد.
